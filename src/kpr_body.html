Beranda

Kelola Data

Upload di tiap bagian hanya memperbarui data bagian itu. Data tersimpan di perangkat ini; bagikan ke anggota lewat Snapshot HTML.

Keragaan KPR

Gabung KAP DLY harian atau Master Keragaan (sheet Database). Tanggal baru ditambahkan ke riwayat; RKA diperbarui bila ada sheet Database RKA.

Pipeline Brispot

Pipeline BRISPOT (sheet Pipeline, OnHand, Ref_Batal, Rencana Realisasi RM). Menggantikan data pipeline sebelumnya.

Produktivitas RM

Database bulan harian, Produktivitas Monthly, atau Produktivitas RM History (sheet Database). Hanya bulan di file yang diperbarui.

Simulasi KPR

Tabel Perhitungan Suku Bunga KPR (sheet Tabel Suku Bunga). Menggantikan tabel suku bunga sebelumnya.

Foto RM

Pilih satu atau beberapa foto sekaligus. Nama file = nama RM (mis. Melva Novelina S.jpg). Foto dipotong persegi otomatis; foto lama dengan nama sama diganti.

Bagikan ke anggota

Simpan dashboard beserta data saat ini menjadi satu file HTML. Kirim lewat WA/email; anggota cukup membukanya.
